# Sdtm-dm-ae-vs-mapping
SDTM DM , AE and VS domain creation using SAS on dummy data.

PROJECT:SDTM DM and AE domains built from sample raw data.
TOOLS: SAS, CDISC SDTM.
  The files contains the data to map or derivate the data from raw data to make it into a standard datasets, contains labelling, core variables, derivation data, labelling and all the complete demographic, adverse events and vital signs of a subjects, who are involved in studies.
